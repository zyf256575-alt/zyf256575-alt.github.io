# 游戏截图批量整理设计

## 目标

把 Steam 本地截图补充进个人游戏履历，同时保持详情页轻量、图集有代表性，并保留原图放大浏览能力。

## 范围

- 保持《戴森球计划》《艾尔登法环》《怪物猎人：世界》现有已确认图集不变。
- 小图集直接整理：潜水员戴夫、God of War Ragnarök、WUCHANG: Fallen Feathers、PUBG: BATTLEGROUNDS、Ghost of Tsushima DIRECTOR'S CUT。
- 大图集先做候选总览，不直接写入：Hollow Knight: Silksong、Black Myth: Wukong。

## 图片约定

- 每张入站图片保留 `*-original.jpg`，供灯箱查看原图。
- 生成 `*.webp` 作为详情页展示图，生成 `*-thumb.webp` 作为轻量缩略图。
- JSON 使用现有 `src`、`thumbSrc`、`fullSrc`、`alt` 字段，不引入新数据结构。
- 不虚构截图标题；`alt` 仅使用“游戏名 + 游戏截图 + 序号”的中性描述。

## 筛选规则

- 小图集逐张视觉检查，仅移除明显重复、纯菜单或无辨识度画面。
- 大图集按时间顺序生成带编号联系表，供后续筛选 6–10 张代表图。
- 原始 Steam 截图不删除、不移动。

## 验收

- JSON 引用的三种图片资产全部存在。
- 现有图集顺序与数量不变。
- 全量测试通过；本地网页能显示缩略图并打开原图灯箱。
- 大图集联系表可读且编号能映射回原始文件。
