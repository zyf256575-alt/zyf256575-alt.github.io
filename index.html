关于

物理学硕士在读，AI Coding / AI 全栈实践者。我关注的不只是调用模型，而是以 DataBase 保存用户持有的长期资产，用 Obsidian 完成人类可读的可视化与关系导航，再让 Codex、Claude Code 和项目规则接入真实流程。

目前项目覆盖个人 AI 知识与协作、短视频生成、游戏资产管线和 AI4Science 科研计算。领域不同，但共同目标是把上下文、纠偏经验、证据和人工验收留在模型之外，让协作能力随使用持续演化。

业余大部分时间给了运动、音乐和 3A 游戏。魂系的晦暗美学、黑神话的中式表达、巫师 3 的叙事厚度，无形中塑造了我对世界的想象；而《戴森球计划》那种从零编织星河的浪漫，大概也是为什么我喜欢把管线一格一格跑通，看着系统活起来。
